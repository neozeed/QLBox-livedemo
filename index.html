What is running?

QLBox runs the cartridge’s own boot program automatically with these settings:

qlbox --mount ql26inv.mdv --timing ql

This is live emulation, not a recording. The browser build uses QLBox’s existing CPU, video and audio synthesis. QL timing remains an experimental model; this demo is a compatibility demonstration, not proof of perfect hardware accuracy.
